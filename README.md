# One-Liner Laughs

**"I whispered a secret to my smart speaker — now every ad I see already knows it."** (79 characters)

## Run

```sh
node main.ts
```

This writes the joke to `/output/entry.txt`.

## Why it's funny

The joke takes the familiar image of whispering a secret to a trusted confidant and twists it: the listener isn't a person at all, it's a smart speaker — and the secret doesn't stay secret. It leaks straight into the ad network, so every ad you see already knows it. The laugh lands on a privacy anxiety everyone recognises: the device that is always listening is also always telling. One sentence, one beat, one punchline.
